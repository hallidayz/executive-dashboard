# Tartan Colors (Heritage Reference)

Tartan lineages are **heritage / storytelling reference only**. They are **not** the default digital product chrome for the executive dashboard.

Corporate UI defaults always use [corporate-colors.md](corporate-colors.md) (Navy / Gold / Canvas).

## Source

Visual lineages are documented in the companion PDF:

`halliday_brand_guides.pdf` (repo root)

That PDF is image-heavy; treat the following as the four lineage slots to expand when print swatches are transcribed.

## Four tartan lineages

| Lineage | Symbolism (intent) | Digital use |
|---------|--------------------|-------------|
| 1 — Corporate Dress | Formal identity; navy-forward | Prefer corporate navy/gold tokens |
| 2 — Hunting / Field | Earth and muted greens | Optional seasonal / print only |
| 3 — Celebration | Gold and warm accents | Gold as CTA only in product UI |
| 4 — Legacy / Archive | Historical weave variants | Documentation / merch — not app chrome |

## Rules for product UI

- Do **not** introduce multi-stripe tartan as a primary background in the dashboard.
- Do **not** replace status red/amber/green with tartan yarn colors.
- If a marketing surface needs tartan texture, keep it full-bleed heritage media and keep interactive UI on the corporate palette.
