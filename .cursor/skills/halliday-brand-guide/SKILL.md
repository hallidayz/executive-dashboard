## Quick rules

- Navy `#02295B` → headers, nav, primary text
- Gold `#FDA700` → high-impact CTAs only (~10%); label `#02295B`
- Off-White `#D6D6D6` → main backgrounds (~60%)
- Charcoal `#333F3F` → body copy
- Silver `#B0B5B3` → borders / dividers
- Muted `#D8D8D6` → card fills
- Status stays rose / amber / emerald — never remapped to brand gold
